# Проверка релиза `/ps plot`

## Развёртывание и откат

Совместимая связка: Paper 1.21.10 или 1.21.11, WorldGuard 7.0.15, WorldEdit 7.4.2 и Vault 1.7.3.

Проверено вживую 2026-07-27 на Paper 1.21.11 (build 132): WorldEdit 7.4.2 подхватывает адаптер `v1_21_11`, WorldGuard 7.0.15 и плагин загружаются без ошибок. Плагин объявляет `api-version: 1.17`, поэтому к конкретной версии Minecraft не привязан.

Перед заменой сделайте резервные копии текущего ProtectionStones JAR, папки `plugins/ProtectionStones/` и `plugins/WorldGuard/worlds/<world>/regions.yml` каждого тестового мира. Штатно остановите сервер, замените JAR на `target/protectionstones-2.10.5.jar`, запустите сервер и проверьте лог загрузки ProtectionStones, WorldGuard, WorldEdit и Vault. Не удаляйте region data и не тестируйте merge/unmerge без отдельной резервной копии.

Для отката остановите сервер, верните старый JAR и сохранённые данные регионов, затем снова запустите сервер.

## Подготовка

Нужны два игрока без OP и без WorldGuard bypass: `Owner` и `Member`. Создайте обычную PS-зону и plot внутри неё. Добавьте `Member` в родителя, затем выполните `/ps plot kick <plot> Member`. Для геометрии отдельно подготовьте тестовый merged U-образный/дырявый parent и чужой WG-регион.

## Матрица ручных тестов

В колонке «Факт» запишите результат, в «Статус» — `PASS` или `FAIL`, а при ошибке приложите фрагмент лога.

Прогон 2026-07-27/28, Paper 1.21.11, без провайдера экономики (`create_cost` временно `0.0`). Проверка велась одним аккаунтом: игрок оставался владельцем участка и оператором, но был исключён из `owners` родительского региона и внесён в `ps-plot-denied`. Это допустимая замена второму игроку, потому что запрет по коду не применяется только к владельцу родителя, а WorldGuard оператора и так пропускает — то есть блокировал именно наш listener.

## Матрица для `/ps plot unkick`

Добавлена вместе с командой `unkick` (состояние «прохожий»). Ни один сценарий пока не прогонялся в игре.

Подготовка: игрок `Member` добавлен в родительскую зону через `/ps add`, участок создан владельцем. Нужен ещё `Guest` — игрок, не добавленный никуда.

| № | Проверка и шаги | Ожидаемый результат | Факт | Статус / лог |
|---|---|---|---|---|
| U1 | `kick Member`, затем поставить `interact allow`; Member жмёт кнопку, Guest жмёт кнопку | Guest может, Member нет — блокировка сильнее флага |  |  |
| U2 | `unkick Member` при `interact allow`; Member жмёт кнопку, открывает калитку | Может, наравне с Guest |  |  |
| U3 | Тот же Member пробует сломать и поставить блок, ударить корову, вылить ведро | Всё запрещено — публичный флаг не даёт строить |  |  |
| U4 | Снять флаг: `flag interact none`; Member снова жмёт кнопку | Запрещено |  |  |
